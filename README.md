# Subversive website

Public site for Subversive, a farmhouse brewery, taproom and kitchen in Catskill, NY.

Nothing is built yet. Start with [`docs/SPEC.md`](docs/SPEC.md).

- `docs/SPEC.md`: the full design and engineering spec
- `docs/mockups/`: early direction studies
- `docs/source/`: menu PDFs and image URLs from the old site
- `content/`: menu, site info and seed events as data
- `public/brand/`, `public/photos/`: logo marks and photographs from the current site
