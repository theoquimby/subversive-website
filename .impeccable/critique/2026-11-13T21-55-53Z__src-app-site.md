## Design specificity verdict

Half authored, half kit; never reaches the register of the beer label.

- Authored: the food menu (intro boxes, pills, three-up burgers), the wordmark slash and the mobile menu's slash wipe, the barley band, the gold New York map, "This keg's kicked."
- Interchangeable: the Home hero (fat serif, two pill buttons, rounded photo), Visit, the footer.
- Wrong brand: Events and the game-night hero read as a sports-bar app; on a game night the first screen sells a Knicks game.
- Missing: the label. Thin gold on spruce appears in one section; the beer is shown as 20 px glass icons.

Deterministic scan: clean (one advisory in src/app/dev/kit/kit.css:636, a false positive: a measurement grid in the dev kit).

## Priority issues

- [P0] Scroll layering is broken. (1) /menu: the sticky bar flips between top 60 and top 0 across scrollY 214–272 on a phone (27 toggles of data-stuck in 60 px; 188–263 on desktop): MenuEnhancer's stuck test feeds back through the translate. (2) /events: h2.event-month__label sticks at top 60/76 with no rule for a hidden header, so tickets show in the gap above it. (3) All routes: #site-header is transparent for scrollY 22–80, page text passes under it; on the Overtime home hero the header ink is 1.05:1 against the hero. Fix: one rule for the sticky stack, an opaque pinned header, a scroll test asserting nothing shows above a pinned bar. Command: /impeccable harden.
- [P0] The menu's section chips never appear after in-site navigation (the pre-paint inline script does not run on client navigation, so data-show is never set). Fix: set state in code that runs on every arrival. Command: /impeccable harden.
- [P1] The first screen is forgettable, and on game nights it sells basketball: cream then a flip to black after load (CLS 0.063 on a phone), an NYK slab over the photo, an unreadable countdown. Fix: the beer is the hero object in the label's gold and spruce; the game is one line; render the final state. Command: /impeccable bolder.
- [P1] Three visual registers, no label DNA: black sports-app (hero, events, footer), cream print (menu), spruce and gold (one section); generic line icons, a blue badge, a starburst, tilted tickets. Fix: two registers. Spruce and gold for brand moments; cream print for utility. Commands: /impeccable colorize, /impeccable typeset.
- [P1] Motion is mostly generic or cheap and nothing is playable: grey wash page change with a blinking header; photo frames empty then a beige band slides off; starburst pop; hero stickers appear after ~3 s on a phone (observer margin). Fix: few authored moments: a real pour, tap-to-fill beers, the slash as the page change, honest press states. Commands: /impeccable animate, /impeccable delight.
